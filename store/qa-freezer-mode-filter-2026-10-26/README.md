# Компактный фильтр режимов морозилки

Вместо второго ряда чипов — кнопка «Режим ▾» рядом с поиском. Три варианта доступны в меню; выбранный фильтр отражается подписью и фоном кнопки. При выборе «Все режимы» возвращается нейтральная подпись «Режим».

## Проверки

- `:app:testModernDebugUnitTest`, `:app:testA10DebugUnitTest`: 91 + 91, без ошибок и пропусков.
- `:app:assembleModernDebug`, `:app:assembleModernRelease`, `:app:assembleA10Release`: успешно; release lintVital прошёл. Полный lint не повторялся.
- Временная read-only копия NMS_Test, Android 17, ширина 360dp. Проверка на физическом телефоне не проводилась.
- Тестовые данные: 9 приложений, из них 5 мягко приостановлены и 4 отключены через adb на эмуляторе. Команды заморозки из приложения через root/Shizuku не проверялись.
- Меню отмечает текущий режим. «Мягкая» показывает 5 приложений, «Глубокая» — 4.
- «Глубокая» + поиск Gmail даёт одно приложение; «Мягкая» + тот же запрос — пустой список.
- «Глубокая» + «Разморожены» даёт пустой список; возврат к «Все» снова показывает 4 приложения.
- Выбор «Глубокая» сохраняется после изменения системного шрифта на 150%. Подпись кнопки и все пункты меню помещаются.
- Возврат к «Все режимы» восстанавливает подпись «Режим». Светлая и тёмная темы проверены визуально.
- Эмулятор закрыт без сохранения.
