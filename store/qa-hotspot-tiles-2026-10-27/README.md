# Проверка раздачи 3.30

27.10.2026. Временная read-only копия NMS_Test, Android 17, emulator-5580. Физический телефон не использовался. На снимках `HotspotLab` диапазоны, трафик и клиенты синтетические; это проверка интерфейса. Плитки и окно их добавления — настоящие SystemUI.

## Проверки

- 110 тестов modern + 110 a10, без ошибок. Дополнены сценарии явного запрета диапазона при старом списке каналов, подтверждённой поддержки с пустыми каналами, ограничений API для bridged AP, неполного ответа прошивки и различения выбранного/фактического диапазона при подсветке плитки.
- Debug и обе release-сборки, lintVital. Первое падение анализатора Kotlin/UAST устранено изменением объявления классов плиток; итоговая сборка прошла без отключения проверок. Полный lint не повторялся.
- В системном окне добавлены «VPN · 2,4 ГГц» и «Proxy · 5 ГГц». Выбран большой размер плиток, обе подписи и действие «Запустить» проверены на второй странице шторки. Нажатие VPN 2,4 без root обработано; ошибок AndroidRuntime не зарегистрировано.
- Высота основной VPN-кнопки при 100%: 168px / 64dp вместо прежних 294px / 112dp. Светлая тема 100%, тёмная 150%: текст и значки помещаются.
- При имитации поддержки 2,4/5 в fixture отсутствуют 6 ГГц и dual в основном выборе и редакторе.
- Минифицированный `HotspotReadCli` возвращает булевы флаги поддержки диапазонов. В этой AVD: 2,4=true, 5=false, 6=false, bridged=false. [Снимок только возможностей](radio-support.json). Это свойства эмулятора, не телефона владельца.
- На финальной debug-сборке подставлен локальный кэш «доступно только 2,4»: на настоящем экране скрыты пресеты 5/6, компоненты их плиток отключены, сохранённый `VPN:6` остаётся в Prefs. Проверка не запускала AP. Минифицированная release-сборка установлена поверх debug: настоящий экран и плитка VPN 2,4 открываются без падений.

## Ограничения

Сетевая логика запуска переиспользуется из 3.29. Эта проверка не подтверждает реальную передачу трафика клиентов через VPN/Proxy, работу 6 ГГц или двух AP на телефоне. При смене частоты точка перезапускается. Плитки сочетаний запускают раздачу; остановка остаётся в обычных VPN/Proxy-плитках и на экране точки доступа. На Android 10 выбор частоты через API не поддерживается, поэтому плитки сочетаний скрыты.
