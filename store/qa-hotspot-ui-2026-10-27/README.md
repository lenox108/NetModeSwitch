# Проверка экрана точки доступа 3.29

27.10.2026. Временная read-only копия NMS_Test, Android 17, emulator-5580, ширина 411dp. Телефон владельца не использовался. Скриншоты `HotspotLab` показывают синтетические диапазоны, клиентов и трафик; это не результаты измерения сети. Fixture присутствует только в debug APK и не исполняет сетевые команды.

## Проверено

- 104 + 104 unit-теста без ошибок. Новые сценарии: повреждённые/пустые настройки быстрых кнопок, сохранение пароля и остальных Wi-Fi параметров, проверка конфигурации перед остановкой, отказ остановки/записи, игнорирование записи системой, совпадающий диапазон без перезапуска, применение ранее сохранённой частоты к ещё работающему старому AP, незанятый диапазон в bridged-режиме без лишнего рестарта.
- `assembleModernDebug`, `assembleModernRelease`, `assembleA10Release`, release lintVital. Полный lint не повторялся; ранее оставались ошибки в других частях проекта, см. QA 3.28.
- Кнопки VPN/Proxy показывают отдельные действия и выделяют включённый режим; общая остановка доступна и для прямого режима.
- Шесть готовых быстрых кнопок. В fixture проверен выбор VPN/Proxy/напрямую, общая остановка, создание «6 ГГц · Напрямую», сохранение после остановки процесса и повторного открытия экрана, удаление через долгое нажатие.
- 6 ГГц видны и выбираются. Взаимное исключение двух строк диапазонов, повторное нажатие на текущий вариант, выбор «Авто», маршруты VPN/Proxy/напрямую и появление настройки прокси.
- Имя/защита и дополнительные параметры раскрываются; раскрытие сохраняется при смене конфигурации экрана. Последние кнопки доступны прокруткой и не перекрываются нижней панелью.
- Светлая тема 100% и тёмная 150%; подписи маршрутов помещаются, значения трафика переносятся целиком. В проверяемом запуске нет записей AndroidRuntime о падении.
- Настоящая HotspotActivity открывается без root/Shizuku, запуск и сохранение Wi-Fi отключены. Минифицированный release: `ApConfigCli check radio=2:0` успешно проверяет builder; недопустимый `radio=4:0` отклоняется. Настройки до и после обеих проверок совпадают; тест не запускал точку и не менял её конфигурацию. [Результат](cli-check.txt).

## Ограничения

Unit-тесты проверяют порядок операций запуска и обработку отказов через подставное устройство. Они не подтверждают работу Wi-Fi оборудования телефона. Реальный запуск сочетаний через root приложения на телефоне, 6 ГГц, два одновременных AP, скорость SIM/VPN и сохранение соединения клиента при смене маршрута не измерялись. При смене частоты работающая точка перезапускается, клиенты временно отключаются. Настройки Wi-Fi и фактические рабочие диапазоны могут различаться из-за ограничений Android; карточка «Сейчас» показывает доступные фактические данные.
