# Морозилка: сортировка и добавление приложений

В меню ⋮ основного экрана «Порядок приложений» переименован в «Сортировка». Доступны название, дата добавления (новые/старые сверху), сначала размороженные и ручной порядок. Избранное сохраняет приоритет; сортировка общая для списка и папки, выбор сохраняется между запусками.

`IceApp.addedAt` — время добавления в морозилку, независимое от запуска, заморозки и разморозки. Поле записывается в JSON и резервную копию; импорт существующего приложения сохраняет его дату. Старые записи без даты получают 0, их относительный порядок определяется сохранённой последовательностью списка. Реальные исторические даты не восстанавливаются. Для одной даты также используется последовательность добавления.

Кнопка «Добавить» открывает общий выбор сразу на «Не выбраны». Уже добавленные приложения передаются как выбранные и скрыты в этом фильтре. Новая отметка скрывает строку; через «Выбранные» её можно снять. Восстановление Activity сохраняет текущий фильтр, поиск и отметки. Другие вызовы выбора без нового extra сохраняют начальное «Все».

## Проверки

- Offline-сборка с JDK Android Studio, одним worker, Kotlin in-process и отдельным buildDirectory `/tmp/nms-freezer-sort-build`. Команды: `:app:testModernDebugUnitTest :app:testA10DebugUnitTest :app:assembleA10Debug :app:assembleModernRelease :app:assembleA10Release`.
- 161 + 161 unit-тест без ошибок и пропусков. Три новых теста покрывают даты независимо от состояния/названия/ручного порядка, старые записи и одинаковые даты, фильтрованный список и приоритет избранного.
- Обе release-сборки прошли R8 и lintVital. Полный lint не запускался. Подпись обеих APK проверена `apksigner`, SHA-256 сертификата совпадает с отчётом выпуска 3.4.
- Одноразовый read-only `NMS_A10`, Android 10/API 29, `emulator-5594`: сортировка в обе стороны, старые записи, перезапуск процесса, порядок в папке с прокруткой, начальный фильтр при добавлении, скрытие выбранных, снятие отметки, повторное добавление, реальная запись даты нового приложения, сохранение старых дат при сериализации.
- Проверено сохранение фильтра «Все», поиска Chrome и выбора при пересоздании Activity после смены шрифта. Общий выбор без extra по-прежнему начинает с «Все».
- Светлая тема 360dp/100%, тёмная 320dp/150%. Подписи дат переносятся; длинный список сортировки прокручивается, кнопки закреплены.
- Итоговая A10 release-APK повторно установлена в эмулятор: выбор сортировки, новый порядок и начальное «Не выбраны» проверены ещё раз. Debug-компоненты отсутствуют.
