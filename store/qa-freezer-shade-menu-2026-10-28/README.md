# Меню приложений в списке морозилки из шторки

Предыдущая доработка добавляла меню только в `FreezerActivity`. По уточнению пользователя нужный экран — папка `ThawActivity.folder()`, которую открывает долгое нажатие плитки «Морозилка» в шторке. Меню сохранено в обоих местах, его состав задаёт общий `IceAppMenu`.

В папке доступны открытие, заморозка/разморозка, временная разморозка, возврат автозаморозки при удержании, избранное, ярлык, карточка и удаление с подтверждением. Папка наблюдает изменения предпочтений и обновляет значки, порядок и состав списка с сохранением поискового запроса. Карточка открывается сразу для выбранного ключа, включая клоны. Множественный выбор остаётся доступен на основном экране.

## Проверки

- `./gradlew --offline --max-workers=2 -Dorg.gradle.parallel=false :app:testModernDebugUnitTest :app:testA10DebugUnitTest :app:assembleA10Debug :app:assembleModernRelease :app:assembleA10Release` в `/tmp/nms-freezer-longpress-build`: успешно, включая R8 и lintVital. 127 + 127 unit-тестов без ошибок и пропусков. Полный lint не запускался.
- Одноразовый read-only NMS_A10, Android 10, 360dp, пять установленных тестовых приложений. A10 release APK установлен в эмулятор. Плитка добавлена только в его шторку.
- Проверен именно жест: раскрытие шторки → удержание настоящей плитки 1200 мс → список с `grid` и кнопками «Настроить / Заморозить всё» → удержание Chrome → меню внутри этого списка. Основной `FreezerActivity` для этого действия не открывается.
- Избранное переключается у Chrome, звезда и обратный пункт меню обновляются сразу. При поиске Chrome запрос сохраняется после действия.
- Временная разморозка Gmail на 15 минут задаёт удержание; «Вернуть автозаморозку» снимает его только у Gmail. Удержание Photos сохраняется. Оба действия оставляют папку открытой.
- Отмена удаления оставляет Gmail в списке. Подтверждение убирает только Gmail и сразу обновляет папку.
- Карточка из меню папки открывается для Chrome. На основном экране по-прежнему открывается меню с «Выбрать», множественный выбор работает.
- Повторён настоящий жест плитки в тёмной теме со шрифтом 150%. Меню читается, последнее действие доступно прокруткой.
- У обоих APK проверены package name, версия 3.30 / 3.30-a10, versionCode 85, minSdk 34 / 29 и прежний сертификат `40ed2e2df70aec2d7072ff3d3437364de80928691b6d632a95f008c9b98308f2`.

Тестовые состояния мягкой и глубокой заморозки выставлены через shell только в одноразовом эмуляторе. Привилегированное выполнение из приложения, запрос ярлыка лаунчеру и физический телефон не проверялись. Эмулятор закрыт без сохранения. Публикация не выполнялась.
