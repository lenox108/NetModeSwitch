# Компактные кнопки морозилки — 26.10.2026

Исправлена нижняя панель множественного выбора с фотографии: короткое «Все» и две кнопки с полными подписями. Стиль NMS.IceAction общий с карточкой, папкой и кнопками настроек. IceActionLayout перестраивает пары кнопок по фактической ширине текста и иконок. Панель занимает место под списком, а не перекрывает его.

## Проверки

- `:app:testModernDebugUnitTest :app:testA10DebugUnitTest`: 91 + 91 тест, без ошибок.
- `:app:assembleModernDebug :app:assembleModernRelease :app:assembleA10Release`: успешная сборка, lintVital пройден. Полный lint не повторялся (прежние ошибки проекта описаны в HANDOFF.md).
- Одноразовая read-only копия NMS_Test: Android 17, 1080 × 2400, density 480, ширина 360dp. Тёмная/светлая темы; шрифт 100% и 150%.
- При 100% панель имеет высоту 64dp, кнопки — 48dp; все три подписи помещаются в одну строку.
- Выбор четырёх приложений; «Все» выбирает девять и становится недоступной. Последнее приложение «Часы» доступно прокруткой и видно целиком над панелью.
- При 150% две основные кнопки становятся вертикально; их левые/правые границы совпадают. Нижняя граница списка совпадает с верхней границей панели.
- Проверены папка, кнопки ярлыка/плитки в настройках и карточка приложения после перехода на общий компонент.
- В приложении эмулятора нет root/Shizuku. Тестовое состояние заморозки выставлено через shell только в одноразовом эмуляторе. Реальные действия заморозки из приложения и телефон владельца в этой задаче не проверялись.
