# Возврат в морозилку и индикатор снежинки

Причина исчезновения списка: `ThawActivity` одновременно обслуживал временные команды ярлыков и саму папку. В манифесте у него были `noHistory=true`, `excludeFromRecents=true` и пустая task affinity; после запуска приложения метод `open()` дополнительно вызывал `finish()`.

Папка вынесена в обычную `IceFolderActivity`: собственная задача `com.netmode.switcher.freezer`, `singleTask`, обычная непрозрачная тема, название «Морозилка» и отсутствие исключения из истории/недавних. Запуск приложения сохраняет Activity. Выбранная группа и поле поиска остаются, новое открытие общей папки использует существующую задачу. Новый ярлык другой группы обновляет выбор через `onNewIntent`, очищая старый поиск. Переход в управление также сохраняет папку для возврата кнопкой «Назад». При возвращении однократно синхронизируется состояние заморозки.

`ThawActivity` остаётся временным исполнителем заморозки/разморозки и одиночных ярлыков приложений. Старые ярлыки папки и открытия группы перенаправляются в `IceFolderActivity`; создавать их заново не нужно. Новые ярлыки открытия и долгое нажатие плитки сразу используют обычный экран.

По уточнениям пользователя кнопка с двумя параллельными линиями удалена из общей панели групп. «Порядок групп» остаётся в меню группы (долгое нажатие на чип или ⋮ рядом со счётчиком) и меню ⋮ управления. В папке значки всех приложений цветные; у замороженных есть снежинка, у размороженных нет. Дополнительные подписи «Заморожено/Разморожено» в папке убраны. Экран управления сохраняет свои подробные статусы.

## Проверка интерфейса

Сценарий `check-ui.py` использует только одноразовые read-only эмуляторы, требует `ro.kernel.qemu=1` и root ADB. В качестве перехода в другое приложение выполняется тот же `cmd package resolve-activity` / `am start`, который использует `Freezer.launchScript`. Отдельно проверено, что попытка запуска из списка без root/Shizuku не закрывает папку. Привилегированный канал приложения и разморозка на физическом телефоне не проверялись.

Android 10 debug: старый ярлык группы → постоянная задача, цветные значки со снежинкой, отсутствие кнопки с линиями и лишних подписей, перестановка из меню, сохранение поиска/группы после «Назад», настоящий выбор карточки из Pixel Launcher Recents, повторное открытие общего ярлыка и другой группы без дубликата, «Настроить → Назад», пересоздание при 320 dp / 150% и тёмной теме. Все проверки прошли; результаты и превью — `a10-debug/`.

Тот же полный сценарий повторён на итоговой A10 release-APK: все 9 проверок прошли, результаты — `a10-release/`. Журнал падений пуст; Android 10 эмулятор закрыт без сохранения.

На итоговой modern release-APK в одноразовом Android 17 подтверждены 5 основных проверок: старый ярлык открывает обычную задачу, порядок меняется через меню, попытка запуска без привилегированного канала сохраняет список, «Назад» из часов возвращает ту же задачу/группу/поиск, а нажатие её карточки в нативных недавних также возвращает папку. Результаты и снимки — `modern-release/`. Русское название «Часы» определяется из списка; для надёжного ADB-ввода используется короткий поисковый запрос. Остальные 4 проверки полного сценария подтверждены на Android 10.
