# NetModeSwitch 3.4 (86)

Релиз объединяет текущие доработки правил, точки доступа, региона Wi-Fi, морозилки и диалогов после опубликованной 3.30 (`405c42e`). Номер **3.4** задан пользователем. Внутренний код повышен с 85 до 86.

- [Описание GitHub](github-release-3.4.md) включает новые правки и возможности опубликованных 3.27–3.30.
- [Текст для 4PDA](4pda-3.4.txt) содержит только изменения после 3.26, без тегов `list`.
- [README](../README.md) описывает приложение, установку, ограничения и сборку.
- [Результаты проверок](qa-release-3.4.json), [SHA-256](SHA256SUMS-3.4.txt).

## Проверки

158 unit-тестов modern и 158 a10, без ошибок, падений и пропусков. Обе release-сборки прошли R8 и lintVital. Проверены package name `com.netmode.switcher`, версии `3.4` / `3.4-a10`, versionCode 86, minSdk 34 / 29 и отсутствие debug QA-компонентов в release-манифестах.

Сертификат обеих APK совпадает с прежним релизом: `40ed2e2df70aec2d7072ff3d3437364de80928691b6d632a95f008c9b98308f2`. Повышенный versionCode и прежняя подпись позволяют обновление поверх 3.30 с сохранением данных. Фактическая установка этого выпуска на физический телефон и новый UI-прогон не выполнялись; предыдущие проверки отдельных функций описаны в HANDOFF.

Первая параллельная компиляция завершилась нехваткой памяти Kotlin. Итоговый успешный прогон выполнен с JDK Android Studio, последовательно и с компиляцией in-process:

```sh
./gradlew --offline --no-daemon --no-parallel --max-workers=1 \
  -Pkotlin.compiler.execution.strategy=in-process \
  '-Dorg.gradle.jvmargs=-Xmx4096m -Dfile.encoding=UTF-8' \
  :app:testModernDebugUnitTest :app:testA10DebugUnitTest \
  :app:assembleModernRelease :app:assembleA10Release
```

Контрольные хеши исходников до и после успешной сборки совпали. Отпечаток списка исходников записан в JSON проверок. Локальный журнал: `/tmp/netmodeswitch-release-3.4-build-sequential.log`.

## Дополнение исходников от 29.10.2026: действия плиток Amnezia

Исправлено определение состояния плиток AmneziaVPN и AmneziaWG: команда «Выкл» пропускается, если VPN уже отключён, даже при работающей фоновой службе. Повторные команды сериализованы, неизвестное состояние не вызывает нажатия, тайм-аут не приводит ко второму переключению. Версия не менялась. Это дополнение исходников само по себе не заменяет опубликованные APK и их контрольные суммы. Проверки и ограничения: [отчёт](qa-amnezia-tiles-2026-10-29/README.md).
