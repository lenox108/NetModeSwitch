# Кнопки редактора скрытия уведомлений

В общем `NotifRuleEditor` форма прокручивается отдельно от закреплённой нижней панели. «Сохранить» и «Отмена» всегда расположены горизонтально; у панели нет прокручиваемого контейнера. У сохранения остаётся полное accessibility-описание «Сохранить правило». В существующем правиле удаление доступно значком корзины рядом с заголовком, с подсказкой «Удалить правило».

## Проверки

- Воспроизведено прежнее поведение Material 3: кнопки переносились вертикально, «Отмена» обрезалась, удаление требовало прокрутки. [До исправления](before-large.png).
- Debug-сборка и обе release-сборки успешно завершены, включая R8 и lintVital. Полный lint не запускался. [Лог итоговой сборки](build.log).
- `:app:testModernDebugUnitTest`, `:app:testA10DebugUnitTest`: 127 + 127 тестов, без ошибок, падений и пропусков.
- Временный read-only NMS_Test, Android 17: 360dp / шрифт 100%, 360dp / 150%, 320dp / 150% в тёмной теме. Обе подписи видны полностью, кнопки лежат в одном ряду и не имеют прокручиваемых предков. Границы кнопок не меняются после прокрутки формы.
- С открытой клавиатурой панель остаётся доступной. Нажатие «Сохранить» передаёт введённое значение в callback; «Отмена» закрывает окно без сохранения; корзина вызывает callback удаления. Debug-only `NotifRuleLab` не сохраняет правила и не меняет каналы уведомлений. [Результаты](results.json).
- Физический телефон и фактическое скрытие уведомлений этой проверкой не охватывались. Сборки созданы из текущего рабочего дерева. Для итоговой проверки использован отдельный каталог сборки: промежуточная общая debug-сборка содержала несогласованные ресурсы диалога, после отдельной пересборки ошибка запуска отсутствует.
