# Цвет и заливка снежинки в компактном списке

Компактный список различает фактическое состояние `IceApp.frozenAs`: мягкая заморозка — голубая снежинка в светлом круге с обводкой, глубокая — контрастная снежинка на сплошной фиолетовой заливке. Для размороженного приложения остаётся обычная серая кнопка заморозки. Цвета адаптированы для светлой и тёмной темы.

В одной колонке индикатор встроен в прежнюю кнопку с областью нажатия 48 dp; круг имеет диаметр 36 dp. Когда узкие колонки или массовый выбор скрывают действия, рядом с названием остаётся отдельная метка 24 dp. Высота компактной строки сохраняется 48 dp. Кнопка объявляет действие и текущее состояние, строка — название и состояние; отдельная метка декоративная. Подсказка кнопки содержит полное состояние.

`IceModeIndicator` собирает круг и существующий вектор снежинки. Составной значок сохраняет собственные цвета при очистке tint внутри MaterialButton. `iconGravity="textStart"` центрирует увеличенный значок, предотвращая обрезание справа. Обычный список сохраняет подробную строку состояния и прежнее оформление кнопки.

Версия сохранена: 3.4 / 86, A10 — 3.4-a10. Физический телефон не используется. Сценарий `check-ui.py` жёстко привязан к одноразовому read-only `NMS_A10` на `emulator-5584`, проверяет признак эмулятора, очищает только его копию данных приложения и создаёт состояния через Android shell. Конфигурация намеренно отличается от текущего состояния: Chrome настроен на мягкую заморозку, но отключён глубоко; Gmail настроен на глубокую, но приостановлен мягко.

Сценарии: одна/две/три колонки, массовый выбор и выход из него, тёмная тема при 320 dp и 150% шрифта, разморозка с повторным использованием строк, обычный список. По PNG проверяются цвета фона и снежинки, центрирование круга; по иерархии — доступные описания и область нажатия. Отдельно проверяется сброс фиолетового фона после разморозки без перезапуска процесса.
