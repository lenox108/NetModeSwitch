# Выключение выбранного VPN — 28.10.2026

«VPN → Выключить» в начале, конце и блоке разблокировки показывает выбор VPN-приложения. Начало и каждое окончание сохраняют собственную цель. «Любой подключённый VPN» сохраняет прежнюю семантику.

Если владельцем VPN является другое приложение или выбранный VPN уже не подключён, выполнение пропускается до root-команд, восстановления always-on и нажатия плиток; состояние другого VPN не записывается для последующего возврата. После отключения выбранного приложения появление другого VPN не считается переподключением выбранного.

Для пользователя: окончание правила точки доступа → «Задать вручную» → «VPN / Выключить / Amnezia», затем «Плитки приложений / Happ / Вкл». Порядок задать перетаскиванием за ≡.
