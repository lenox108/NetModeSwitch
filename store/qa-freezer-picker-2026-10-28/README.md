# «Не выбраны» при добавлении приложений

В общем `AppPickerActivity`, который открывается кнопкой добавления в морозилке, добавлен третий чип «Не выбраны». Он оставляет только приложения без отметки. Уже добавленные в морозилку передаются в текущий выбор и тоже скрываются. После выбора приложения строкой или чекбоксом список сразу обновляется. По умолчанию по-прежнему открывается «Все».

## Проверки

- `:app:testModernDebugUnitTest`, `:app:testA10DebugUnitTest`: 121 + 121 тест, без ошибок и пропусков.
- `:app:assembleModernDebug`, `:app:assembleModernRelease`, `:app:assembleA10Release`: успешно, включая R8 и lintVital. Полный lint не запускался.
- Временный read-only NMS_Test, Android 17: переход из морозилки, выбор строкой и чекбоксом, исчезновение выбранной строки, счётчик, просмотр выбранных и снятие отметки.
- Сохранение Chrome в морозилку и повторное открытие добавления: Chrome скрыт в «Не выбраны», остальные доступны после окончания загрузки списка.
- Поиск Chrome: пусто в «Не выбраны», приложение видно в «Все». Сброс выбора возвращает Chrome в «Не выбраны» с тем же поиском. Переключение скрытия системных приложений не возвращает выбранный Chrome.
- Фильтр, поисковый запрос и выбор сохраняются при пересоздании экрана после смены темы и шрифта.
- Светлая тема, обычный шрифт: [превью](unselected-light.png). Тёмная тема, шрифт 150%: [превью](unselected-dark-large.png). Чипы переносятся на новые строки, подписи читаются полностью.
- Физический телефон и команды заморозки не проверялись. APK не опубликованы; прежние файлы релиза не заменялись.
