# Регион Wi-Fi — 28.10.2026

Добавлены «Настройки → Wi-Fi → Регион Wi-Fi» и переход рядом с выбором диапазона точки доступа. Страны показаны по-русски, есть поиск по названию/коду, ручной ввод двух латинских букв, всемирный режим `00` и отдельный возврат автоматического определения. Выбор в списке заполняет поле; изменение выполняется только кнопкой «Применить код».

Применение использует штатную `cmd wifi force-country-code enabled XX` / `disabled`. Перед изменением проверяются реальные UID и наличие команды, затем проверяются код завершения и новое состояние Wi-Fi-службы. Повторная проверка UID стоит непосредственно перед изменением. Команды сериализованы; операция завершается и при закрытии Activity. Читаются отдельно выбранный код, принудительное переопределение и код драйвера. `00` не считается автоматическим режимом. Полный Wi-Fi dumpsys не попадает в интерфейс/журнал.

Настройка действует до перезапуска службы/телефона: автоматического восстановления после загрузки и постоянного опроса нет. Модули root могут менять её независимо. Каналы зависят от драйвера/прошивки. После возврата в точку доступа обновляется информация о диапазонах и каналах.

## Проверки

- 15 новых unit-тестов: нормализация, запрещённый ввод, отделение выбранного кода от драйвера, автоматический/всемирный режимы, неполный вывод, отказ без root/без команды, повторная проверка UID, отрицательный код завершения, обязательное подтверждение результата. Общий набор: 158 + 158 тестов, без ошибок.
- Одноразовые read-only AVD: Android 17/API 37 `emulator-5590`, Android 10/API 29 `emulator-5592`. Физические устройства не использовались, исходные AVD не сохранялись.
- Android 17: production `WifiCountryClient` запущен через debug CLI с реальными shell-командами. `RU`, `JP`, `00` подтверждены как override, затем переопределение снято. Во время опыта драйвер оставался `US`, поэтому факт изменения override не выдаётся за изменение драйвера. UID 2000 получил отказ без изменения состояния; неверный код отклонён. См. `android17/commands.json`.
- Android 10: штатной команды смены страны нет; попытка корректно отклонена, состояние до/после одинаково. Код драйвера читается. См. `android10/commands.json`.
- Настоящий экран в обоих эмуляторах: кнопка применения недоступна без root, список стран, фильтр `JP`, перенос выбранного кода в поле без изменения Wi-Fi. `no-root.*`, `countries.*`, `search.xml`, `selected.*`.
- Итоговый интерфейс проверен в `final-light/` (Android 17, 360 dp / 100%) и `final-dark-large/` (Android 10, 320 dp / 150%): поиск `JP` выдаёт «JP · Япония», кнопка отмены видна над клавиатурой, после выбора клавиатура закрывается. `checks.json` и изображения сохраняют результат.
- Оба реальных перехода из настроек и точки доступа, а также возврат из региона в точку доступа прошли без сбоя; `navigation.json`.
- Визуальные проверки включают тёмную тему, ширину 320 dp и шрифт 150%. Файлы `dark-large.*` используют помеченный debug-only пример JP/US для проверки отображения; они не подтверждают root из Activity и не выполняют изменения.

Привилегированный транспорт приложения через реальный KernelSU/Magisk/Shizuku и физический Wi-Fi-чип не проверялись. Эмулятор подтверждает работу Wi-Fi-службы и обработки ответа, но не доступность радиоканалов на телефоне.

## Источники механизма Android

- [WifiShellCommand, Android 14](https://android.googlesource.com/platform/packages/modules/Wifi/+/refs/heads/android14-release/service/java/com/android/server/wifi/WifiShellCommand.java): root-команда force-country-code, чтение get-country-code.
- [WifiCountryCode](https://android.googlesource.com/platform/packages/modules/Wifi/+/refs/heads/main/service/java/com/android/server/wifi/WifiCountryCode.java): override, выбранный код и код драйвера — разные состояния; применение может ожидать готовности интерфейса.
