# gitpull

В `~/.zshrc` загружается `tools/gitpull.zsh`. После обновления уже открытого
терминала: `source ~/.zshrc`.

- `gitpull` обновляет ForPDA-master и NetModeSwitch независимо: ошибка одного
  репозитория не мешает проверить другой.
- `gitpull /путь/к/репозиторию` обновляет только указанный репозиторий; можно
  передать несколько путей.
- Требуется ветка `main` без незавершённого merge/rebase/cherry-pick.
- Локальные коммиты переносятся поверх `origin/main` через `pull --rebase`.
- Незакоммиченные изменения, индекс и новые файлы временно сохраняются в stash
  и восстанавливаются после pull. При конфликте stash остаётся доступен; команда
  возвращает ошибку. Игнорируемые файлы не входят в stash.
- Конфликт rebase отменяет начатый командой rebase и возвращает локальные файлы.
- В NetModeSwitch дополнительно переносятся ещё отсутствующие патчи из старых
  веток `origin/ccr-*`. Сравнивается содержимое патчей через `git cherry`.
  Изменения Codex, влитые в `main`, приходят обычным pull.
- Команда не отправляет локальные коммиты на GitHub.

Проверки на временных локальных репозиториях: `python3 tools/test-gitpull.py`.
