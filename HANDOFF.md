# Текущее состояние проекта

Последнее обновление: 22.10.2026. Подготовлена версия **3.19**, `versionCode = 74`: «И ещё если» (`Extras.kt`, `AppFreezer.onExtras`), предупреждение о конфликтах (`AppRule.conflicts`), шаблоны, сторож root-команд (`Privileged.throttle`, `RateGuard`) ([изменения](store/changes-3.19.txt)). Не сделано из списка: действия «звук/громкость/«Не беспокоить»/яркость/тайм-аут/частота экрана», уведомление, HTTP, shell; триггеры «уведомление от приложения / работает в фоне», USB, Android Auto, будильник, закат/восход, лимит трафика, незнакомый Wi-Fi; мгновенное определение приложения (спецвозможности); внешний API + NFC.

Версия **3.18**, `versionCode = 73`: действие «Переподключить моб. сеть» (`AppFreezer.reconnect`, не чаще раза в 5 мин), «При срабатывании: молча / уведомить / спросить» (`RunNotices.kt`, `Prefs.askedStarts`: окно открыто, действия ждут ответа; неподтверждённое окно закрывается без конца и не наследует) ([изменения](store/changes-3.18.txt)). Проверено на эмуляторе с имитацией зарядки: вопрос, «Выполнить», уход условия без ответа, уведомление «сработало».

Версия **3.17**, `versionCode = 72`: условие «Интернет пропал» (`Trigger.NO_INTERNET`, логика — `InternetLoss.kt`, слежение — `ConditionWatch.readInternet`/`startNetProbe`) ([изменения](store/changes-3.17.txt)). Проверено на эмуляторе: блокировка трафика iptables → проба дважды не прошла → система сняла VALIDATED → через 30 с правило сработало; после снятия блокировки — «internet back».

Версия **3.16**, `versionCode = 71`: сцены — `Trigger.MANUAL`, ярлыки и меню иконки (`Scenes.kt`), таймер выключения через `reconcile` и общий будильник; переход между правилами «Приложение» без переподключения VPN ([изменения](store/changes-3.16.txt)). Проверено на эмуляторе без root: редактор, сохранение, ярлык на рабочем столе, запуск сцены. Полный цикл вкл/выкл с root — только на телефоне.

Версия **3.15**, `versionCode = 70`: правила «Приложение» — задержка выхода, системные окна и вкладки браузера не считаются закрытием, «не считать выходом», экран выкл ≠ закрытие; правило может состоять только из «В конце» ([изменения](store/changes-3.15.txt), логика — `AppPresence.kt`, тесты — `AppPresenceTest`). APK: `store/NetModeSwitch-3.15.apk`, `store/NetModeSwitch-3.15-a10.apk`, на устройстве не проверялись.
