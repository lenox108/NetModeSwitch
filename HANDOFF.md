# Текущее состояние проекта

Без номера версии (после 3.25): плитки правил в шторке (`RuleTiles.kt`). Плитки объявляются в манифесте, поэтому их 5 (`RuleTile1Service`…`RuleTile5Service`), привязка «слот → правило» — `Prefs.ruleTiles` (локально, в резервную копию не входит). В редакторе правила меню «Кнопка в шторке»: занимает свободный слот и вызывает `requestAddTileService` (Android 13+; раньше — подсказка добавить «Правило N» вручную); отказ освобождает слот, удаление плитки из шторки или правила — тоже. Нажатие идёт через ту же кнопку, что в виджете правил (`Scenes.press` → `WidgetActionReceiver`). Пустая плитка по нажатию открывает выбор правила (`RuleTilePickActivity`). Перерисовка — по изменению ключей правил в `Prefs` (`RuleTiles.refresh`, никогда не из `onStartListening`); плитка в открытой шторке перерисовывается напрямую. Проверено: сборка modern/a10, unit-тесты, lint без замечаний к новому коду; на телефоне и эмуляторе не проверялось.

Последнее обновление: 23.10.2026. Версия **3.24**, `versionCode = 79`: сортировка списка правил (`RuleOrder.kt`, `RuleSort`: по типу / названию / сначала работающие / вручную), свой порядок перетаскиванием за ⠿ в `AppRulesActivity`, сортировка и порядок в резервной копии. Проверено: unit-тесты (`RuleOrderTest`); на телефоне не проверялось ([изменения](store/changes-3.24.txt)).

Версия **3.23**, `versionCode = 78`: правило «Приложение» считает открытым приложение в мини-окне (PiP) или на разделённом экране — `AppPresence.Behind` по событиям использования (paused ≠ stopped), `ConditionWatch.readBehind`; условие «Android Auto» видит CarConnection и получило задержку выхода. Включает исправление 3.22 (VPN не отзывается через 3 с). Проверено: unit-тесты; на телефоне не проверялось ([изменения](store/changes-3.23.txt)).

Версия **3.21**, `versionCode = 76`: фиксация TTL ставит и IPv6 Hop Limit (`NMS_HL`, `NetworkScripts.hl`); если ядро не умеет — блокировка IPv6 клиентов (`NMS_TETHER6`) только при включённом TTL; переключатель IPv6 убран, `Prefs.disableTetherIpv6` остался только для импорта старых копий. `CheckActivity`: блокировка «назад» через `OnBackPressedCallback` (жест не вызывал `onBackPressed`). Проверено: lint, unit-тесты, прогон на эмуляторах Android 17 и 10 (все экраны, 26 типов правил в редакторе, виджеты) — падений нет ([изменения](store/changes-3.21.txt)).

Версия **3.20**, `versionCode = 75`: действия «Системные настройки» (`SysSettings.kt`, возврат через `#sys:KEY`), уведомление / HTTP / shell (`OneShots`); условия «Уведомление приложения» (`NotifWatch.kt`, доступ к уведомлениям выдаётся через `cmd notification allow_listener`), «Чужой Wi-Fi», «Будильник», «Закат и восход» (`Sun.kt`, координаты в `Prefs.sunPlace`), «Трафик» (NetworkStatsManager, все SIM вместе, опрос раз в 10 мин), «Android Auto», «USB»; «Мгновенно» (`AppWatchService`, спецвозможности); запуск извне (`Api.kt`: ссылка netmode://run и намерение com.netmode.switcher.RUN, ключ `Prefs.apiKey`) ([изменения](store/changes-3.20.txt)).
